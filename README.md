# Aizhan Consult — ИИ-ассистент врача (хакатон)

Врач ведёт приём — система записывает разговор, ИИ определяет, кто говорит (врач или пациент), собирает
полный анамнез, формирует документ консультации со ссылками на клинические протоколы МЗ РК и после
подтверждения врачом отправляет запись в МИС. Все данные вымышленные.

## Запуск

```bash
copy .env.example .env      # впишите ANTHROPIC_API_KEY (файл .env в git не попадает)
docker compose up --build
```

| Сервис | Адрес |
|---|---|
| Приложение врача | http://localhost:5173 |
| Backend (API) | http://localhost:8000/docs |
| МИС (имитация внешней системы) | http://localhost:8001 |

Без Docker: `powershell -ExecutionPolicy Bypass -File .\run-local.ps1`.

## Сценарий демо

1. Откройте приложение и МИС (в приложении МИС встроена справа внизу, можно и отдельным окном).
2. Выберите пациента. **В МИС появляется пустая карточка** консультации («Ожидает заполнения»).
3. Запишите разговор (кнопка «Начать запись») или нажмите «Загрузить пример».
4. ИИ расставит роли врач/пациент, соберёт анамнез, покажет «что уточнить у пациента»,
   красные флаги и страницы протоколов МЗ РК. Диагноз и лечение помечены как **предложение ИИ**.
5. Врач проверяет форму, подтверждает и нажимает «Отправить в МИС» — **карточка в МИС заполняется**
   (диалог + документ). Отправка заблокирована, пока врач не подтвердил форму.
6. Документ можно сохранить («Сохранить документ» — файл для Word, «Печать / PDF»).

## Как устроено

- `frontend` — React + TypeScript + Vite: запись, диалог, динамическая форма по шаблону специальности.
- `backend` — FastAPI: шаблоны консультаций (`backend/app/templates/*.json`: терапевт, офтальмолог,
  невролог), вызовы Claude API, поиск по протоколам МЗ РК, правила красных флагов.
- `mis-mock` — FastAPI: имитация внешней МИС (приёмы, карточки, страница МИС).
- Протоколы МЗ РК: `backend/app/protocols/` (PDF, индекс, текст по страницам; собирается `scripts/build_protocol_data.py`).

## Безопасность

- ИИ заполняет только то, что прозвучало в диалоге; диагноз и лечение — предложения, окончательное решение и
  подтверждение за врачом (`doctor_approved`).
- Красные флаги определяются правилами в коде (`red_flags.json`), а не решением модели; пока врач с ними
  не ознакомился, форму подтвердить нельзя.
- Лечение подбирается только по найденным страницам протоколов; если протокол не подходит, поля остаются пустыми.
- Секретов в репозитории нет: ключ читается из `.env`.
